# Resume fonts

Static Latin-subset TrueType files, embedded into resume PDFs when chosen in
the builder (src/lib/pdf/fonts.ts). Fetched from Fontsource
(https://fontsource.org, `latin-{400,700}-normal.ttf`). Each file carries its
own copyright and licence in its `name` table.
